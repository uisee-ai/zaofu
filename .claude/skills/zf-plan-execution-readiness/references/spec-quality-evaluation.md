# 规格质量评估协议

用于方法评估、对照研究、Plan/Critic 校准；复用现有评审工件，不创建自动语义评分
门禁。评分是带证据的评审判断，不是产品验收、Task 完成状态或自动实施授权。

## 三种证据分开

1. 能力：方法/模板是否明确，是否接入实际入口；外部工具按公开代码/文档评估，
   未检查的实现标未知。方法参考不与完整工具硬比运行时能力。
2. 产物：固定 Plan/Task Spec 的来源、语义、责任及版本是否一致。明确目标 digest、
   覆盖范围、反例和遗漏，不因字段数、场景数、Critic approve 就推导质量分。
3. 效果：独立交接/实现/验证是否减少澄清、遗漏和返工。未执行为 NOT_RUN，不能
   用模板、渲染回放或机械单元测试补齐效果分。

## 固定输入和公平比较

对照前冻结需求、仓库基线、共享合同、模型/参数、预算、工具权限、方法版本和
评估规则；同一需求不能只给候选补充澄清。主比较只改方法，其他差异作为混杂项。
保留失败、超时、缺环境和全部样本，不只展示成功的一次。若仅有文档证据，给出
能力评分与证据等级，不称“实测胜率”或“质量提升”。公开资料未说明不等于不支持。

评分可用 0–5：0=经核查缺失，1=零散描述，2=基础可用但明显缺口，3=主要关系明确，
4=完整方法及入口有证据，5=另有多样本独立重复验证。未知用 N/A，不填 0；列出
适用维度、权重、每格依据/扣分理由与证据等级，并给替代权重检查排序是否稳定。
预先定义维度，避免按己方优势事后挑权重。文档声明、源码检查、聚焦测试、单次
真实样例和受控重复实验分别标记。分数只对所述用途和证据集合有效。

## 校准与实际交接

先从来源提炼预期与反例，再看候选；评审者不得把作者的自评或既有 approve 当作
答案。真人/Agent 是否参与作者工作、是否同模型、是否可识别方案来源均需记录。
只更换角色不意味着不同模型、盲评或完全独立。拿出含合理正例的样本，避免只训
“找问题”；评审要给具体位置、违反条款及最小反例，无证据的偏好不阻断。

建议覆盖：
- 一个简单用户旅程及失败恢复；
- 一个权限/多主体状态场景；
- 一个跨任务集成场景；
- 一个已有行为修订/迁移；
- 一个当前未知但不阻塞其他工作的决定；
- 一个看似细致、实则不可执行的循环依赖。

样本按项目适用性选择，不强制每个项目包含全部领域。标准答案独立保存，不能
放进被测作者的输入包；校准样本不能同时充当盲测效果证据。

| 检验 | 提供材料与动作 | 记录的结果 |
| --- | --- | --- |
| 独立交接 | Task Spec + 指定同版引用 + 仓库，移除作者聊天背景 | 复述行为/责任是否正确，澄清问题及定位时间 |
| 反例 | 注入有来源的失败不变项遗漏、串任务绑定等变体 | 找到/漏掉的反例、误报合理正例、证据和严重性 |
| 依赖 | 检查本片仅依赖已完成前置能否验证 | 未来产物、自证完成、循环或孤立实现 |
| 变更 | 改一条共享合同，保持其他来源不变 | 找对/漏掉/误报的消费者与需要失效的旧证据 |
| 实施 | 按规格实施并由另一验证者对原始需求检查 | 需求遗漏、集成返工、测试是否只重复实现 |

不同层级分别报告分母：语义反例识别、正例误报、交接澄清和实现返工不合成一个
无解释的百分比。时间和 token 使用实测记录，未定价不能记免费。预先冻结的停止
条件达到即停止；不得无限重试选最好结果。

## 教学用正反例校准

以下是评审方法示意，不是盲测输入或已经执行的评测结果。实际实验另外冻结输入，
将来源推导的答案单独保存，不能把此表一起提供给被测作者。

| 主题 | 合理正例 | 应能定位的反例 |
| --- | --- | --- |
| 失败恢复 | 保存成功后发布新状态；失败保留旧值与输入 | 只检查错误提示，却先覆盖内存和表单 |
| 权限 | 所有者能修改，非所有者被拒且原状态不变 | 只隐藏按钮，仍允许非所有者经 API 修改 |
| 共享场景 | 功能 AC 与装配 AC 各有命令并指向同一行为 | 场景挂两任务，却只有一边有可定位责任 |
| 修订 | 新规则替换具名旧规则，其他场景保持有效 | 重写 Spec 时丢掉未被批准删除的恢复行为 |
| 未来决定 | 将未入本期的同步方案登记到未来立项前 | 用未来同步决定阻塞当前本地功能，或猜成已批准 |
| 执行依赖 | 当前片只依赖已完成前置；整体验证留给后继 | 当前片以未来装配产物为完成条件，形成循环 |

## 结论模板

- 对象/输入/方法版本、比较条件、证据等级及混杂项；
- 各维度分数、证据、适用性和未覆盖项；
- 明确通过的结构/产物/效果层级；
- 具名问题、最小改进、责任与下一次可复现验证；
- 保留 NOT_RUN、负面结果和不确定性，不把一轮通过推广成稳定能力。
