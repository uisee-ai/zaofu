# 跨域义务与真实行为生产者

每个跨域义务检查范围是否匹配：

- “所有页面具备真实接口/Schema/错误协议”不能只映射到“项目字段保存正确”。
  全局决定登记负责契约取得与各域覆盖；各业务片负责其运行行为；最终整体验收
  聚合逐域证据。一个负责人不等于一个局部 AC 足以证明全部要求。
- “所有资源职责治理正确”不能只由“未知身份被拒绝”证明；按资源、动作、
  主体/职责、范围及撤销变化列允许/拒绝组合，绑定业务生产者与鉴权测试。
- 权限用例的执行 owner 从实际动作推导，不能直接采用资源目录的维护 owner。
  例如资源基础管理并不生产后续复合事务；该事务中的消耗、占用或关联权限，应随
  事务命令生产者验证。前置片只验证自身已就绪的授权规则或管理行为，并明确范围；
  不把未来命令的完整操作挂在前置命令上，也不以替身执行冒充真实生产者验证。
