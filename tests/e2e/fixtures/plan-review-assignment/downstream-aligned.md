原始需求 R1。CLI 和 HTTP 共用认证策略，v2 起具有 reader 角色可读取自己的草稿，其他人拒绝；成功不写文件。两入口的 v1 均拒绝全部读取。
此次 Plan 修改共享策略 T-P，保留 CLI 适配器 T-C 和 HTTP 适配器 T-H 的实现。任务和命令登记仍由 T-C、T-H 各自生产入口证据，产品尚未实现。
CLI 矩阵 AC-C：合法 reader 的 stdout 返回旧值、exit 0；无权读取 exit 非零且旧文件不变。
HTTP 矩阵 AC-H：合法 reader 读自己的草稿返回 200 及旧值，无权读返回 403 且旧文件不变。
产品独立验收按 R1 调用两个入口，分别核查上述四种结果和存储字节。
