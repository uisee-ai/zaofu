# 协议渲染器：隔离执行恢复验证

为本地工具作者提供 Python 3.11 标准库命令 `python render_protocol.py`。
它从 stdin 读取一个 JSON 对象，按当前协议的 input_key 取得字符串，在 stdout 输出
协议 output_prefix 加字符串和一个换行。合法空字符串和中文保持原值；非法 JSON、
缺字段、额外字段、非字符串以非零退出并在 stderr 说明原因，不输出成功正文。
README 给出运行、测试及错误示例。无网络和第三方依赖。

当前权威协议为 `${EXTERNAL_PROTOCOL}`，由 Owner 管理，只读。
规划时必须读真实文件，记录 version、input_key、output_prefix 和来源摘要；实现时将
已批准协议固化在代码中。产品运行时不读取该外部文件，不做自动兼容旧协议。
本地自动测试检查所有上述行为；独立 Verify 还需读取当前外部协议与已批准版本比对。
外部版本变化意味着合同变化：报告版本冲突及当前实现 commit，请求重新规划，不能
直接改旧 Plan 或在旧合同下静默实现新版。新 Plan 明确新版协议，保留可复用实现，
重新审批后按新合同完成。版本 2 不再接受版本 1 字段。

当前讨论只形成 PRD。后续 Owner 审批 Plan 后授权隔离项目内实施、测试、正常 Git
提交及交付。外部协议变化是本验证的授权场景，不授权 Agent 修改协议文件。任务采用
能独立验收的最小切片；若一个 Task 足够，不为并行人为增加角色或任务。
