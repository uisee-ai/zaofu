# 定向消息、等待与持久作业

依据 [设计规格](../../docs/design/specs/213-zaofu-antigravity-borrowings.md)。P1 定向板帖与有界等待；P2 显式授权的持久作业生命周期、时区和重试。

- 用隔离账本、可控时钟重放 -> verify: 仲裁与消费幂等，旧绑定不能获新授权，错过、重叠、停用与未知效果可区分。
