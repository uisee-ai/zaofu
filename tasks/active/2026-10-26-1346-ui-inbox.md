# Inbox 队列与阅读区

> 状态: active

来源：[设计 189](../../docs/design/189-gr8r-ui-alignment.md)。用户 2026-10-26 已批准本批设计、backlog 与实施。

## 范围

实现紧凑左侧队列及右侧完整详情，保留类别、通知聚合、预览、审批/拒绝/Ack，窄屏列表详情切换。

## 验收

选择/阅读/返回 -> verify: 零写入且位置保留；审批、拒绝、预览 -> verify: mock API 浏览器断言。

## 实施与验证

双栏阅读、显式审批/拒绝/Ack、完整预览、阅读零写入、移动返回焦点与滚动位置均通过 mock API 浏览器断言。

完整命令、边界和证据位置见 [设计 189 验证记录](../../docs/design/189-gr8r-ui-alignment.md#本批验证结果)。本任务实现已完成，等待实现提交号后归档。
