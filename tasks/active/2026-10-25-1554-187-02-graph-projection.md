# 版本和 Run 隔离的统一关系投影与 API

> 状态: active
> 来源: [设计 187](../../docs/design/187-ai-sdlc-graph-workbench.md)；187 §3、§6、§11、§12。

## 实施范围

- 复用已有 Workflow compiler、Task Pipeline、coverage、trace 和事件读模型，生成通用图节点/有类型关系。
- 绑定 Request/配置/计划/Run/Task/Operation/Attempt 和证据；准备阶段也可见。
- 投影只读、脱敏、显式诊断缺失数据，支持稳定身份与来源游标。
