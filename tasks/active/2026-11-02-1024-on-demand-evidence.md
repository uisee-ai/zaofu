# 可追溯的按需证据读取和增量恢复

> 状态: active

## 问题与目标

现有必读按整个计划来源展开，session 续接仍可能全量读取；增量交付仅 shadow。保留原始来源及权限，以 operation/attempt 身份、来源摘要、选择范围和真实读取回执约束只读取所需数据；不可将交付回执伪装为阅读或审核结论。

## 验收

- 同一 operation 的有效来源和完整页段在续接后继续使用 -> verify: 不重复发送已验证区间，剩余页段可继续且结果准入接受完整真实账本。
- 来源摘要、attempt/角色/session/权限或计划合同不匹配 -> verify: 不继承不兼容回执，读取与准入保持 fail closed。
- 按已核验范围读取指定原文 -> verify: Agent 可按需读取其获授权切片，完整来源仍可取回且任何截断/缺页不能冒充完整阅读。
- 必读分页的多来源与重复来源 -> verify: 别名独立授权，输入按摘要去重，不改变冻结 operation 的内容与来源。
