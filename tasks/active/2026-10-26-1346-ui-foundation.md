# UI 基线与本地偏好

> 状态: active

来源：[设计 189](../../docs/design/189-gr8r-ui-alignment.md)。用户 2026-10-26 已批准本批设计、backlog 与实施。

## 范围

统一中性色、字号、强调色与密度 tokens；实现可校验的本地偏好模型、旧主题迁移和跨标签同步。

## 验收

旧主题迁移、非法偏好、异常 localStorage -> verify: 偏好单元测试；主题与系统变化 -> verify: 浏览器断言。

## 实施与验证

偏好模型单元测试覆盖旧主题迁移、非法字段、损坏存储和系统语言；浏览器验证系统主题切换、跨标签同步。

完整命令、边界和证据位置见 [设计 189 验证记录](../../docs/design/189-gr8r-ui-alignment.md#本批验证结果)。本任务实现已完成，等待实现提交号后归档。
