# 设计调研、实现交接与验收

用于有设计需求的 PRD 作者、Planner 和 Critic。按实际问题展开，消费已有授权、
Requirement/AC、决定、设计附件和 Task 引用；不新增固定工作流阶段或设计状态机。

## 输入与有界调研

先核实目标用户、核心任务、设备与环境、品牌、技术限制、现有组件与设计规范，
区分必须遵守的约束、可探索空间和待决项。已有知识能回答时复用；新领域、重要
交互、流程或架构仍有未知时，围绕具体问题检索行业产品、相似任务或官方设计系统。

优先官方资料、可访问产品/演示、公开源码和技术案例。保留 URL/版本、查阅时间、
观察范围与限制，区分实际观察、厂商声明、推断和项目提案。无法访问标未核验；
截图不能证明后端架构，营销声明不能证明性能。检索用必要抽象问题，遵守素材授权。

说明参考点、适用/不适用条件、调整理由、重要替代方案与验证方式；不规定竞品数。
证据足以支持当前决定或剩余问题只能由用户/实验回答时停止。参考产品的功能和数值
不能自动成为本项目需求；已有授权选择不因调研重新打开。

## 设计表达与公共约定

| 当前问题 | 适用表达 |
| --- | --- |
| 找到并完成任务 | 信息架构、用户流程、低保真线框 |
| 布局、品牌、视觉方向 | 关键页面效果图与适用状态 |
| 多步交互、反馈、恢复 | 可操作原型与未实现范围说明 |
| 多角色、状态变化 | 泳道图、业务流程或状态图 |
| 系统、接口、数据协作 | 上下文/容器架构、时序或数据关系图 |

先用低成本表达消除关键分歧，按验收需要提高精度。纯后端无需虚构界面；已确认
视觉要求仍需交付。图与正文术语、边界、箭头和失败路径一致；保留可编辑源与预览，
实际渲染检查文字、连线、裁切。流程图可用 Mermaid，界面可用已有设计工具、
HTML/CSS 原型或图像工具。生成候选、参考截图、采纳设计、实现与验证证据分别标识。

不同 Agent 消费同版公共约定：颜色语义、字体、间距、布局、组件与交互。优先复用
现有规范，只为实际新增需要扩展。每项公共变更有整合责任、受影响页面/消费者和
验证路径；局部差异说明原因，避免每个任务维护一套组件。公共规范变更按现有修订。

## 页面交接、适配与就绪

关键页面/交互说明入口、角色、任务、Requirement/AC；内容来源、格式、排序、更新
及示例数据；操作条件、权限、校验、可用/禁用状态、反馈和结果；完成/取消/返回/
刷新/中断后的去向与输入保留；复用组件/接口、实现和验证责任。API/CLI 使用对应
调用与输入输出说明。按适用性覆盖正常、加载、空、错误、无权与冲突。

设备和内容规则说明窄屏重排、长文本/大数据量、语言、日期时区、单位；错误提示
帮助用户修复并继续。按产品要求明确键盘、焦点、对比度等无障碍目标与判据，结合
自动及人工验证，记录限制。短占位文案、自动扫描无报错不能证明实际内容适配或
完整无障碍符合性；具体断点、标准目标和设备范围有依据后确定。

Planner 检查当前任务所需的流程、状态、组件、数据/接口、依赖生产者和验证责任
是否明确，Critic 给出正文位置、证据、影响任务与最小修订。未决项沿用决定登记，
说明负责人、最迟时点、受阻任务及可以继续的工作；高风险可行性问题复用 bounded
Spike。局部可继续不代表整体就绪，图面完整也不构成就绪证据。

例如超时重试语义未知，应阻塞依赖它的重试实现/验收；已有规范下的静态布局探索
可继续。方法不直接调度任务，依赖/顺序通过既有 Plan、受控修订与授权路径落实。

## 同版交接与验收

引用设计来源、版本/ref/digest、适用场景、Requirement/AC/决定及采纳依据。候选
不能当已批准合同；图文矛盾列出影响并修订，旧图保留替代关系。行为改变同步正文、
AC 和任务，纯展示修改说明语义不变。一般已授权细节不重复审批，设计确认不自动
批准实施。沿用既有 companion/handoff 承载记录，不复制 AC/命令或新造强制字段。

Verify 对照已采纳设计检查实现的关键页面和状态，同时按 AC 执行关键旅程 E2E、
适用设备和无障碍检查。先审阅实现是否符合设计，再采用审阅通过的实现截图作为
回归基准；首次生成截图仍是候选，不自动通过。设计效果图保留为依据而非运行证据。

固定或记录浏览器、视口、字体、数据、语言、时间、动画与环境。动态区域遮罩及
差异容限说明理由，不遮蔽关键业务或未授权布局变化。ZaoFu 浏览器 E2E 使用既有
Docker runner 和临时端口规则；其他目标项目遵循自身验证合同。

偏差记录预期/实际、影响、版本和证据，决定修复实现或申请设计修订；批准变更后
同步正文、AC、设计与基准，复验影响范围。不能覆盖基准掩盖失败。功能、视觉、
可用性证据分别报告；未运行保持 NOT_RUN，方法已交付不等于产品已验收。
