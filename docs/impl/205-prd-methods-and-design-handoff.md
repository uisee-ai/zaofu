完成，4/6 表示本轮六项拆分中已完成的任务占比，不是 205 全文成熟度。205 是方法、
代码、实验和产品效果的混合设计，不把方法接线率换算成全文完成度百分比；全文结论
为“部分落地，效果未验证”，具体缺口以上表为准。
