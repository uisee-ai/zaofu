# PRD 与设计交接：使用与验证

本页说明设计 205 本轮落地的方法及其使用边界。方法已经接入作者、评估和规划技能，
并不表示某个具体产品已完成调研、设计、独立评审或验收。

## 从哪里进入

- Channel 合成 PRD：现有合成请求携带阅读、需求证据和设计指导，无需手工绑定技能。
- PRD 独立质量评估：使用冻结的 `prd-quality-review.v2`，沿用 PRD-Q1–Q8，给出每项
  证据和适用性；历史评估保留自身方法与摘要。方法版本变化不修改旧评估结果。
- PRD/Plan 角色：`zf-prd-plan-synth` 读取产品阅读参考，并通过依赖物化
  `zf-plan-execution-readiness` 的设计方法；Planner/Critic 按当前任务前沿消费。
- Web PRD 预览：已有角色入口支持中英文标准章节，保留风险、决定和版本相关入口。
  完整正文仍是同版材料；角色视图不是完整审批范围的替代品。
- 导出：已知目录字段显示中文含义及原始键，未知字段和完整正文保留。当前仍使用
  原有全文布局；四层默认展示与新的离线包能力尚未实施。

## 准备一个可消费的设计

先说明用户、任务、约束和本次未知，复用本地知识；按问题选择行业/产品研究和
线框、效果图、原型、流程或架构图。参考资料保留来源、日期、适用性及推断边界。
现有设计规范和组件作为公共输入，多 Agent 使用同一版本，公共变更有整合责任。

在现有 PRD/companion 中保留图文关系、Requirement/AC/决定和任务引用；交接说明
入口、数据、操作、权限、反馈、状态与恢复，并覆盖适用的设备、内容和无障碍要求。
不要求每项需求创建固定数量的页面、图或表；已有同版信息精确引用即可。

下面是合成的交接示例，所有标识和界面均为说明方法，状态为 NOT_RUN：

| 项目 | 示例 |
| --- | --- |
| 用户/任务 | 有权限的操作员提交库存预留并查询结果 |
| 行为引用 | FR-1/AC-1：库存不足则拒绝，库存不变 |
| 页面状态 | 编辑、提交中、成功、库存不足、无权、结果待查询 |
| 未决决定 | D-1：超时重试是否复用原预留结果，负责人待指定，消费前关闭 |
| 当前可继续 | 按既有组件规范探索布局、整理状态与接口问题 |
| 当前受阻 | 依赖 D-1 的重试操作实现与验收，不能自行决定幂等语义 |
| 设计依据 | 待生产候选，须绑定实际版本及采纳依据，当前无已批准截图 |
| 验收 | 通过提交/查询核对业务结果；按采纳设计审阅关键状态，再建立实现截图基准 |

## 真实读者评审准备

选择简单功能、复杂业务、跨系统需求各一个有来源样本。数量用于覆盖场景，不代表
统计显著性。选定有权提供的原始材料与未参与写作的读者，确认实验的执行范围；
尚缺样本或读者时保留 NOT_RUN，不能用上面的合成示例替代真实评审。

可将以下内容记录到现有评测工件；模板本身不构成新的机器合同：

| 准备内容 | 填写要求 |
| --- | --- |
| 输入冻结 | 样本 ID、来源/ref/digest、正文版本、已有决定、完整范围与未决项 |
| 对照材料 | 基线与候选的固定版本；先同义重排，再单独比较真实生成，记录方法/模型/预算差异 |
| 评审范围 | 本次检查的用户故事、设计与验收；未覆盖部分明确列出 |
| 角色与独立性 | 实际产品/架构/开发读者、是否参与写作、来源标签是否可识别 |
| 观察规则 | 预先确定关键遗漏判据、问题与记录方式；改善目标从基线和负责人决定取得 |
| 实验状态 | NOT_RUN、实际执行记录或具体缺口；不靠填表宣称完成 |

向读者提供材料与任务，不提供预期答案或作者偏好的方案。尽可能隐藏方案来源，
交叉阅读顺序。主持人单独保留与来源逐项绑定的预期答案，完成后再对照：

| 角色任务 | 读者要做什么 | 主持人核对依据 |
| --- | --- | --- |
| 产品 | 复述问题、价值、本批范围和剩余义务，定位当前待决事项 | 已确认原始输入和决定 |
| 架构 | 说明系统/数据归属、失败恢复、依赖及当前可实施边界 | 同版设计合同和未决影响 |
| 开发/验证 | 从行为定位 AC、生产者、依赖、验证入口和责任 | 原始行为、任务映射与证据计划 |

每个回答记录：样本/版本、读者和实际问题、原始回答、用时、跳转、澄清、对应来源、
遗漏/误解、影响及待修订项。预期答案不混入实际回答；保留负面结果、未查范围和
非盲限制。同义重排与生成对照分开报告，不以字数减少代替理解改善。

## 设计验收与结果使用

产品实现后分别检查关键旅程、视觉和适用的设备/无障碍行为。审阅实现符合采纳设计
后，才使用其截图作回归基准；记录环境、数据、字体、视口和动态区域处理依据。
偏差具名记录并决定修复或修订设计，更新依据可追溯；不直接覆盖基准消除失败。

阅读试点发现用于决定最小方法或展示改动。用户研究、原型可用性、真实生成效果、
产品验收及上线指标各需自己的证据，不能从一次阅读测试或自动化测试外推。
现有授权和 schema 继续有效，方法不增加语义硬门禁或自动批准实施。
